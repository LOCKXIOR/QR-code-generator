# QR-code-generator (Qor code)
It uses one of the tools I created for my group project "Medi-Link"

## What do I mean by "It uses one of the tools I created for my group project" ?

Medi-Link is a project that took me a lot of work, by this time it isn't fully ready yet, it merges so many things ! 
As you can see, I use Gen_QR_build26102026. It is simple, I took the idea of naming my project like this from when I download 
cracked games on my computer... I found out what "builds" really meant for games... Although it seems operational, I think it 
still remains some things to perfect it. Gen_QR_build26102026 was created the night 26/10/2026. Long ago, and since Medi-Link has a pause
because of school, I thought I could use it to do an app that can turn things into QR codes ! 

## Why did I do this app ? 

I knew that people paid to do QR codes... And I thought that I wanted some money too! But after all, I deeply think that
it is so much valuable to really help people. That's why I hope that anybody who needs QR codes uses my app!
